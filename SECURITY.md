# Security policy

Report vulnerabilities privately using [GitHub's vulnerability reporting form for Kakehashi](https://github.com/QuangNew/Kakehashi/security/advisories/new).

Include the affected commit, reproduction steps, impact and a minimal proof of concept. Remove API keys, meeting content, recordings and other personal data from reports. Avoid disclosing an unpatched vulnerability in a public issue.

Kakehashi is maintained from the `main` branch. There is no guaranteed response deadline or maintenance commitment for older snapshots.

This policy applies to Kakehashi. NexQ and the model/runtime projects have their own maintainers and security policies.
